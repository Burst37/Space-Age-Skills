# Recipe library (reusable dishes)

Every dish has computed macros (per ingredient, USDA / FatSecret style values). Pick dishes that pass the client's exclusions (check the Contains column), then let carb sides and fat top-ups close the gap to the day's targets. When you create a new dish, add it to this table with the same columns.

Slot codes: B = meal 1 (breakfast or fast-breaker), L = meal 2, D = meal 3.
