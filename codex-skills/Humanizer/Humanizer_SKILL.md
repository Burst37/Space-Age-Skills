# Humanizer — Codex Skill

Use for website copy, emails, scripts, documentation, sales copy, and other prose that reads formulaic or machine-generated.

## Method
1. Preserve factual content and intent.
2. Remove canned transitions, inflated vocabulary, repetitive sentence shapes, excessive headings, symmetrical phrasing, and unnecessary summaries.
3. Vary sentence length and cadence naturally.
4. Prefer concrete language and specific sourced claims.
5. Preserve required SEO keywords naturally when working on websites.
6. Never invent evidence, numbers, testimonials, awards, or user counts.
7. Run a final pass for meaning drift and unsupported claims.

## Output
Return finished copy first. Add brief change notes only when useful or requested.
