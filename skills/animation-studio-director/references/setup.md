# Setup
Create a Picsart account, then in a terminal:
```bash
claude mcp add --transport http picsart-gen-ai https://api.picsart.com/gen-ai/mcp
```
Open Claude Code, `/mcp`, pick Picsart, Authenticate in the browser (no API key). Use the strongest planning model as director. First test (spends nothing):

> show me my Picsart credits, then quote the price of one 1024x1024 image on the cheapest image model. do not generate anything.

Source claims (VERIFY live): 84 video, 66 image, 24 audio models behind one balance; swap a model by changing its id. Every paid generation is quoted before a credit is spent.

No-build fast track: Picsart AI Agents Marketplace (Saga plans a 20/40/80-episode season of 60-90 s episodes, locks faces and voices, shows storyboard frames before spend; Cinema Studio proposes 3 visual directions, breaks shots, locks cast/locations, grades the cut). Starter brief: "I want a 40-episode animated series, 60 seconds each, vertical 9:16. Character / World / Engine / Tone: [one line each]. Show me storyboard frames for episode 1 before generating any video."
