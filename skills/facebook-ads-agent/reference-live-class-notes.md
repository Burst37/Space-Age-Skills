### How to get Facebook Ads API key
1. Use a Facebook Business Portfolio / Business Manager
1. Create a Meta Developer App from the sidebar
1. Add privacy policy + terms to the app
1. Publish / configure the app
1. Create a System User
1. Assign the System User access to:
  1. the dev app
  1. the Facebook Page
  1. the ad account
  1. Instagram account if needed
1. Generate a never-expiring token from the System User
1. Use that token in the agent
1. Validate the token + discover IDs via Graph API
1. Run read/write API tests before using it in production
