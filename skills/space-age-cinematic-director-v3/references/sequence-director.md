# Cinematic Sequence Director — v4.0

## Sequence planning
Build sequences from beats, not random coverage.
1. define beginning information state
2. define final information/emotional state
3. define 2–6 intermediate beats
4. assign one editorial job per shot
5. select coverage that changes scale, angle, depth or movement with purpose
6. preserve character/location/look/screen direction
7. design transitions and handles
8. compile each shot for its generation model

## Lens progression
Avoid random focal-length hopping. Use a family and intentional progression: environmental wide → natural normal → portrait/detail; or compressed long-lens system when the concept calls for it.

## Movement progression
Do not move every shot. Contrast movement with stillness. Match-on-action, motivated direction, speed continuity and eyelines. Preserve travel direction unless crossing the line intentionally.

## Transition design
Prefer motivated transitions: occlusion wipe, foreground pass, match cut, action match, whip when direction supports it, rack-focus bridge, light/dark bridge, graphic match, first/last-frame interpolation. Avoid transition gimmicks that destroy continuity.

## Website hero sequence
Default 8–15s: immediate readable hook; 2–4 beats; crop-safe center action; muted-by-default visual storytelling; text-safe negative space; restrained motion; compression-aware texture; loopable or clean endpoint.

## Commercial/product sequence
Establish product world → material/detail proof → use/action → hero payoff. Logo/text geometry is invariant.

## Character sequence
Establish geography/relationship → readable gesture/action → face/thought → consequence. Identity stability outranks extra motion.

## Continuity ledger
Track per shot: character appearance, wardrobe, props, hand occupancy, location geometry, light direction, time, weather, lens family, color pipeline, screen direction, movement direction, object state and last-frame state.

## Generation handles
For stitched AI sequences reserve stable opening/closing frames. When supported, use reference images, first/last frames or clip extension rather than re-describing identity from scratch.
