# SA-Handoff — Space Age Context Compaction Skill  
  
Adapted from Matt Pocock's `/handoff` skill. Upgraded with SA pipeline-specific  
context fields, agent routing instructions, and VPS/Telegram state capture.  
  
---  
  
## The Problem This Solves  
  
Claude has no memory between sessions. Every cold start = rediscovering context.  
For the SA 5-agent swarm running on DO VPS (`146.190.78.120`), a lost session means:  
- Duplicate work  
- Lost decisions  
- Agent routing errors  
- Half-built pipelines that don't fire  
  
This skill collapses an entire working session into a single markdown block that  
fully restores operational state in any new session.  
  
---  
  
## Trigger Conditions  
  
Fire automatically when:  
  
- `conversation_length > 40 messages` (long session, entropy building)  
- User says "save progress", "checkpoint", "new session", "hand this off"  
- Before handing build to a sub-agent (DeepSeek, Gemini, Minimax)  
- Before a risky bash operation (git push, rm -rf, db migration)  
- End of a build session before client delivery  
- Switching between Claude.ai and Claude Code / Antigravity IDE

## Compression Rules  
  
When summarizing, apply these rules to keep the handoff under 800 words:  
  
1. **Code** → describe what it does, not the code itself. Reference file path.  
2. **Conversations** → extract decisions only. Skip reasoning that led to them.  
3. **Errors** → keep the error message + the fix applied. Drop the debugging journey.  
4. **Design direction** → one sentence per visual decision. No elaboration.  
5. **Locked decisions** → list as facts, not discussions.

## Sub-Agent Handoff Mode  
  
When handing to DeepSeek / Gemini / Minimax for code execution:  
  
```  
HANDOFF TO: [MODEL]  
TASK: [single focused task — no ambiguity]  
INPUTS: [exact file paths or data]  
OUTPUT: [exact deliverable format expected]  
CONSTRAINTS: [any rules — e.g., "no OpenRouter, use direct API", "output HTML only"]  
RETURN TO: Claude Sonnet 4.6 for review  
```  
  
Route coding execution to:  
- **DeepSeek V4 Pro** — complex logic, full files, API integrations  
- **Minimax 2.7** — speed tasks, quick scripts, data transforms   
- **Gemini Flash** — TTS, voice scripts, fast content generation  
- **Gemma** — lightweight tasks, local inference, cost-zero operations  
- **Claude** — orchestration, review, prompt engineering, skill writing
