# Symptom → framework router

Match the user's *symptom*, not their keywords. Pick the first framework listed; add the second only if the problem spans both. Framework details are in `frameworks.md`.

| Symptom the user describes | Diagnose with | Then apply |
|---|---|---|
| "Too expensive", price objections, low close rate on good leads | Value Equation | Grand Slam Offer |
| Don't know what to charge | Value-Based Pricing | Value Equation |
| Calls go nowhere, "I'll think about it" | SPIN | CLOSER |
| People don't get what we do / we sound like everyone | Obviously Awesome | Jobs to Be Done |
| Not enough leads | Core Four | Bullseye |
| Traffic but no sales | AARRR (find the leak) | Awareness levels / Landing page skeleton |
| Signups but nobody sticks | Activation aha | Hooked |
| Launching soon | Launch sequence | Pre-mortem |
| Should I build feature/product X? | Mom Test | Lean Startup |
| Too many priorities | Theory of Constraints | RICE |
| Competitors copying / race to the bottom | 7 Powers | Blue Ocean ERRC |
| Overworked founder, can't scale myself | Leverage | Automate→Augment→Assist |
| What should I automate with AI? | Automate→Augment→Assist | Workflow before agent |
| AI costs too high; frontier model doing simple classify/filter/score steps | System One routing (Jev) | Eval-first prompting |
| My AI/agent output is flaky | Eval-first prompting | Context engineering |
| Content gets no views | Hook→Retain→Reward | Content Pillars |
| Don't know what to post | Content Pillars | Jobs to Be Done |
| Website/brand message unclear | StoryBrand | Obviously Awesome |
| Copy doesn't convert | Awareness levels | PAS / 4 U's |
| Negotiating a deal, salary, partner | Never Split the Difference | Influence |
| Users don't take the action | Fogg Behavior Model | Influence |
| Big scary decision | Reversible vs irreversible | Pre-mortem / Regret Minimization |
| Stuck, procrastinating, inconsistent | Atomic Habits | Inversion |
| Comparing options with uncertain outcomes | Expected value | Second-order thinking |

**Diagnose before prescribing.** If you can't tell which row applies, ask the one question that separates them (e.g. "Are people seeing the offer and saying no, or not seeing it at all?" separates offer problems from lead problems). Most "marketing" problems are offer problems; check the offer first.
